# 作品截圖放這裡

1. 把截圖存成 `.webp` 或 `.jpg`（建議寬 1600px、比例 16:10 或 16:9，單張 500KB 以內）。
2. 檔名用英文小寫與連字號，例如 `sales-app-01.webp`（避免中文與空白，GitHub Pages 比較不會出錯）。
3. 打開 `js/data.js`，在對應作品的 `images: []` 中加入：

```js
images: [
  { src: 'assets/works/sales-app-01.webp', alt: '銷售輸入網頁的表單畫面', caption: '店員用手機輸入當日銷售' }
],
```

4. 重新整理網頁：卡片封面會自動換成第一張截圖，標籤會從「概念示意｜非實際截圖」變成「實際作品截圖」。
   如果檔名打錯、找不到圖片，網站會自動退回概念示意圖，不會出現破圖。

⚠️ 截圖前請先遮蔽：顧客姓名、電話、真實營業額、帳號密碼、試算表網址等私人或機密資訊。

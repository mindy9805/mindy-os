# MINDY OS Codex 建置任務

## 專案定位
MINDY OS 是鐘敏恩（Mindy）的繁體中文互動式個人作品集與 2026/11/6 青年 AI 實戰養成班個人發表網站。核心訊息：**AI 不光是解決問題的工具，也可以創造更多可能。**
副標：一個持續更新中的跨領域探索者。

## 首要指令
請先檢查 `index.html` 的既有樣式、內嵌 JavaScript、圖片來源與互動功能。請沿用、重構與改良現有成果，**不要不經檢查就整站重做**。先提出簡短執行順序，然後直接完成修改、執行測試並提供測試結果。

## 網站定位與設計
- 風格：溫暖自然、簡約、留白、精緻、有趣，品牌色奶油白 `#F7F3EA`、鼠尾草綠 `#A8B99B`、暖杏 `#D9B99B`、深灰綠 `#343B35`。
- 導航：混合式探索地圖＋六大功能卡片。
- 電腦投影優先，同時完整支援 iPhone Safari、Android Chrome、平板。
- 使用繁體中文；不公開電話、家庭背景、私人生活及隱密的個性特質。

## 資訊架構
1. Welcome：開場、Mindy 角色、主題、探索入口。
2. About Me：教育、學校行政、門市營運、跨領域經驗。
3. User Manual：需求觀察、企劃流程、團隊整合、創意發想；合作偏好（先釐清目標、尊重不同意見、重視責任及品質）。
4. Creative Lab：四類作品：豆豆貼營運資料與管理系統（主打）、豆豆貼品牌與商業企劃、日日好日 Daily Bloom UI/UX、AI 課堂其他作品。作品尚缺真實截圖，請用清楚可替換的佔位區，不能假裝示意圖是真實成果。
5. Version History：從 AI 查詢、文案、圖像工具，到 Prompt、試算表、資料架構與網頁原型的整合。
6. Roadmap：持續深化 AI 整合、產品規劃、UI/UX、跨領域合作。
7. Let's Connect：按擅長領域（程式、設計、行銷、數據、企劃、其他）顯示預設合作提案，不收集個人資料。

## 必備互動
- 各內容區導覽與返回。
- 作品類別篩選、作品詳情視窗。
- 簡報模式：8 個節點、前後切換、鍵盤方向鍵、可選講稿、全螢幕失敗備援、手機觸控操作。
- 彩蛋：例如點擊小植物顯示好奇心 +1。
- 保持離線可使用，必要資源自帶，無需 API Key。

## 3D 角色
`assets/` 資料夾放有 Mindy 的角色裁切圖，已確認的外觀為長捲髮、空氣瀏海、圓眼鏡，奶油白上衣、鼠尾草綠服飾。角色有 Welcome、Thinking、Exploring、Surprise 四種姿態。請優先改用本地圖片引用（而非長篇 base64），手機首頁必須完整顯示臉，不可裁切到頭部或眼睛。圖片應提供替代文字。

## 現有手機版缺陷與驗收
- 首頁人物圖片在手機上曾被不當裁切，應確保臉部完整呈現並靠近視覺中心，必要時使用 object-fit: contain 或合適裁切容器。
- Creative Lab 等標題曾在手機上被不自然拆行，請使用響應式字級、合理字距、中文斷行策略，保持易讀而不是強行超出畫面。
- 手機 360px、390px、430px，平板 768px，桌面 1280px/1440px 都需無水平捲動；卡片與操作按鈕正常顯示。
- 導覽與簡報模式可完整操作；一個功能失敗時不使整站失效。
- 尊重 prefers-reduced-motion；提供 focus-visible、適當色彩對比和圖片 alt。

## 開發建議
- 優先保持純 HTML/CSS/JS，除非確有必要才導入框架。
- 可重構成 index.html、styles.css、app.js、assets/；應可直接本機預覽，也能部署 GitHub Pages。
- 加入 README.md，記錄啟動方式、部署步驟、作品圖片如何替換、測試項目。
- 若能執行瀏覽器視覺測試，請取得不同 viewport 的截圖，檢查角色與標題修正。
- 不要編造作品成果、測試數據或外部聯絡方式。

## 發表流程
Welcome → About Me → User Manual → Version History → 營運系統主打 → Creative Lab → Roadmap → Let's Connect。總長約 7 分鐘。最後說：「AI 不光是解決問題的工具，也可以創造更多可能。希望能帶著過去的經驗出發，讓 AI 成為延伸能力與實現想像的橋樑。請多多指教，歡迎交流！」

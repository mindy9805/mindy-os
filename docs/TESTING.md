# 測試紀錄

- 測試日期：2026-11-02
- 工具：Playwright + Chromium（無頭瀏覽器自動化，模擬各尺寸與觸控）
- 範圍說明：以下為 **Chromium 模擬** 結果。尚未在實體 iPhone Safari、Android Chrome 與發表現場投影機上測試，請於發表前親自確認（清單見最下方）。

## 1. 排版（6 種尺寸）

| 尺寸 | 模擬裝置 | 水平捲動 | 首頁角色 | 標題溢出 | JS 錯誤 | 簡報 8 頁水平溢出 |
| --- | --- | --- | --- | --- | --- | --- |
| 360×740 | 小型 Android / iPhone SE 寬度 | 無 | 揮手半身圖，水平置中（偏移 0px），臉完整 | 無 | 0 | 無 |
| 393×659 | iPhone 15（Safari 可視區） | 無 | 同上，偏移 0px | 無 | 0 | 無 |
| 430×932 | iPhone Pro Max | 無 | 同上，偏移 0px | 無 | 0 | 無 |
| 768×1024 | iPad 直向 | 無 | 全身圖，不裁切 | 無 | 0 | 無 |
| 1280×800 | 筆電 | 無 | 全身圖，不裁切 | 無 | 0 | 無 |
| 1440×900 | 桌機 | 無 | 全身圖，不裁切 | 無 | 0 | 無 |

備註：360×740 的簡報第 2、5 頁內容比畫面高 14～26px，可在頁面內上下捲動（不會被裁切）；其他尺寸 8 頁皆一頁可見。

## 3. 穩定性

| 情境 | 結果 |
| --- | --- |
| `js/data.js` 載入失敗 | 頁面文字、圖片照常顯示，無未捕捉錯誤 |
| 瀏覽器停用 JavaScript | 所有區塊內容可見（進場動畫不啟用） |
| 直接雙擊 `index.html`（file://） | 正常運作 |
| 部署在子路徑（模擬 `https://帳號.github.io/mindy-os/`） | 所有資源正常載入 |
| `prefers-reduced-motion` | 動畫與平滑捲動關閉 |

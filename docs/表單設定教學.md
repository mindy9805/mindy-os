# 合作意願表單設定教學（約 10 分鐘，只需做一次）

網站上「我們可以一起創造什麼？」的表單，會把大家填的 **名字、專長、留言** 送到你的 Google 試算表。
GitHub Pages 本身無法儲存資料，所以需要用 Google Apps Script 當「收件處」。

> 設定完成前，按「送出」會顯示「表單尚未啟用」，不會假裝送出成功。

---

## 步驟 1：建立試算表
1. 打開 <https://sheets.google.com>，建立一份**空白試算表**。
2. 左上角命名，例如「MINDY OS 合作意願」。

## 步驟 2：貼上收件程式
1. 在試算表上方選單點 **擴充功能 → Apps Script**。
2. 刪掉編輯區裡原本的 `function myFunction() { }`。
3. 打開專案中的 `docs/google-apps-script.gs`，**全選複製**，貼到編輯區。
4. 按上方的 💾（儲存）。

## 步驟 3：先執行一次 setup（建立工作表）
1. 上方函式選單選 **setup**，按 **▶ 執行**。
2. 第一次會要求授權：
   - 按 **審查權限** → 選你的 Google 帳號
   - 若出現「Google 尚未驗證這個應用程式」：點 **進階** → **前往（專案名稱）（不安全）**
     （這是你自己寫的程式，只會存取這份試算表，可以放心）
   - 按 **允許**
3. 回到試算表，下方會多出「合作意願」和「統計」兩個工作表。

## 步驟 4：部署成網頁應用程式
1. 在 Apps Script 右上角按 **部署 → 新增部署作業**。
2. 點「選取類型」旁的 ⚙ → 選 **網頁應用程式**。
3. 設定：
   - 說明：`MINDY OS 表單`
   - 執行身分：**我**
   - 誰可以存取：**所有人**（這樣訪客不用登入就能送出；他們看不到你的試算表）
4. 按 **部署**，複製「**網頁應用程式網址**」（開頭 `https://script.google.com/macros/s/`，結尾 `/exec`）。

## 步驟 5：把網址貼到網站
1. 打開 `js/data.js`，找到：
   ```js
   form: {
     endpoint: ''
   },
   ```
2. 把網址貼進引號裡，例如：
   ```js
   form: {
     endpoint: 'https://script.google.com/macros/s/AKfy....../exec'
   },
   ```
3. 存檔，把 `js/data.js` 上傳到 GitHub 的 `js` 資料夾（Add file → Upload files → Commit changes）。

> 也可以直接把網址傳給我，我幫你改好 `data.js`。

## 步驟 6：測試
1. 先在瀏覽器打開那個 `/exec` 網址，看到「MINDY OS 表單收件程式運作中 ✓」代表部署成功。
2. 等網站更新（1～3 分鐘），在網站填一筆測試資料送出。
3. 回到試算表「合作意願」工作表，應該會多出一列。測試完可以刪掉那一列。

## 常見問題

**Q：送出後試算表沒有資料？**
- 確認部署時「誰可以存取」選的是 **所有人**。
- 確認 `data.js` 貼的是結尾 `/exec` 的網址（不是 `/dev`）。
- 修改過 Apps Script 程式碼後，要 **部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署**，網址不變。

**Q：統計在哪裡看？**
「統計」工作表會自動計算總填寫數與各專長人數，資料一進來就更新。也可以用 **插入 → 圖表** 做成長條圖。

**Q：別人看得到資料嗎？**
看不到。網站只負責「送出」，資料只存在你的 Google 試算表，除非你主動分享。

**Q：會不會有人亂填？**
表單有基本防護（隱藏的防機器人欄位、字數上限、避免公式注入），但網址是公開的，仍可能有少量無效資料，直接刪除該列即可。
